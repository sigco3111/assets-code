# Lighthouse Cup WebAudio 관중·타격음 합성 코드

외부 파일 없이 Web Audio API로 실시간 합성하는 스포츠 체육관 효과음 클래스(SoundFX)입니다. 공 타격(playHit)·바운스·바닥 스퀴크·휘슬(단·이중)·관중 소음(playCrowd)·판독 알림음 메서드를 오실레이터와 노이즈로 만듭니다. 녹음 음원은 0개입니다.
