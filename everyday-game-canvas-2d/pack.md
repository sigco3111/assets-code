# everyday-game 캔버스 2D 절차적 드로잉 코드 11종

everyday-game 모음집의 Canvas2D 게임 11개 소스입니다. 이미지 에셋 없이 캔버스 경로(path) 그리기로 캐릭터·배경·효과를 전부 그립니다. 분리해서 가져다 쓸 후보를 찾는 참고용 원본 코드이며, 게임 로직과 결합된 상태 그대로 수록했습니다.

## 내용 (game.js 11개, zip)

- `td/` — 크리스탈 타워 수호전: 방어탑 9종·몬스터·지형·궁극기 6종(운석·천둥·빙결 등) 효과 드로잉. 2,157행 단일 파일.
- `metro/` — 지옥철 밀어넣기: 전동차·승강장·승객(눌리고 튕기는 물리) 드로잉.
- `ring/` — 야시장 고리 던지기: 노점·경품 진열·걸어다니는 거위·던지는 고리.
- `smash/` — 사무실 박살 내기: 사무실 가구·부서지는 효과.
- `eat/` — 먹는 대로 싸기: 짐승 캐릭터·음식·식탐 괴물.
- `scrub/` — 때밀이 달인: 손님 등·때수건 드로잉.
- `moyu/` — 월급 루팡 달인: 사무실·사장·인사팀.
- `pop/` — 뽁뽁이 터뜨리기: 뽁뽁이 시트.
- `match/` — 맞선 코너 스피드 매칭: 소개팅 테이블·프로필 카드.
- `chip/` — 가죽재킷 황 사장: 상점·거래 화면.
- `tide/` — 물결 소탕: PNG 스프라이트(별도 팩 everyday-game-tide-sprites)를 불러 쓰는 2D 렌더러. 스프라이트 접속 방식을 보려면 함께 참고.
