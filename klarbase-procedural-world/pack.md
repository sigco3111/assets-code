# Klarbase 절차적 섬 월드 생성 코드

섬 꾸미기 퍼즐 게임 Klarbase의 절차적 월드 생성 모듈 모음입니다. 원작 README 기준 모든 그래픽이 절차적으로 그려지며(모델·텍스처·오디오 파일 없음) 별도 에셋 라이선스가 없고, 섬 데이터도 코드와 같은 MIT입니다.

**라이선스: MIT.** 저작권 표기와 MIT 전문을 유지하면 사용할 수 있습니다(동봉 LICENSE.txt).

## 내용 (zip, JS 14개)

- `world.js` `ground.js` `biome.js` `themes.js` — 월드·지형·바이옴·테마 생성
- `trees.js` `props.js` `fauna.js` — 나무·소품·동물 배치
- `pulley.js` `pip.js` `thumbs.js` `session.js` `softkit.js` `audio.js` `builder 연계 모듈`
- `LICENSE.txt` — MIT 전문 (Copyright (c) 2026 TanmoyP and Klarbase contributors)

## 활용 메모

- 게임 로직과 결합된 상태 그대로 수록한 참고용 원본입니다. 절차적 지형·식생·배치 알고리즘을 가져다 쓰는 용도에 맞습니다.
