# 배달 라이더·광저우 드리프트 절차적 3D 코드 (everyday-game)

웹 게임 「배달 라이더」(https://sigco3111.github.io/everyday-game/rider/)와 「광저우 드리프트」(https://sigco3111.github.io/everyday-game/gz/)의 Three.js 절차적 3D 코드입니다. 두 게임 모두 모델 파일이 전혀 없고, 기본 기하체(박스·원통·구·캡슐)와 셰이더로 모든 화면을 만듭니다. 분리해서 가져다 쓸 후보를 찾는 참고용 원본 코드이며, 게임 로직과 결합된 상태 그대로 수록했습니다.

**라이선스: 알 수 없음.** 원작·한글판 포크 어디에도 LICENSE 파일이 없고(2026-11-20 확인) 재사용 허락은 확인되지 않았습니다. 사용 전 원작자(zhgarylu)에게 확인하세요. 권리자 요청 시 즉시 내립니다.

## 내용 (JS 7개, zip)

- `rider/world.js` — 5×5 블록 구도심 생성: 바닥(아스팔트·차선·횡단보도·물웅덩이 반사)·하늘(태양·구름·별)·건물(인스턴싱 박스 + 셰이더 창문, 밤 확률 점등)·16개 상호 간판 아틀라스·가로등·가로수·비·후처리(블룸·톤·모션 블러). 낮밤과 날씨(맑음·흐림·비) 지원.
- `rider/traffic.js` — 교통: 교차로 신호등(4방향 인스턴싱), 인스턴싱 세단 30대(본체·유리·바퀴·전조등·후미등 분리), 신호 준수·앞차 따라가기·회전·클락션·충돌.
- `rider/hazards.js` — 도로 상황: 교통경찰 검문, 스쿨존, 공사 구간(콘·바리케이드), 갑자기 열리는 차문, 보행자. 캔버스 텍스처 표지판 생성 포함.
- `rider/game.js` — 전동 스쿠터 + 라이더 캐릭터(헬멧·상체 기울기·핸들 폰 거치대), 주행 물리와 카메라.
- `rider/sim.js` — 배달 플랫폼 시뮬레이션(배차·제한시간·정산)과 안내 비콘·화살표.
- `gz/world.js`, `gz/game.js` — 광저우 드리프트: 트랙 생성, 차량 생성기 `makeCar(kind, hue)`(세단·밴·택시·버스), 픽업/배달 광문, 궤적·파티클, 후처리.

## 활용 메모

- 재사용 가치가 큰 부분: `makeCar` 차량 생성기, `traffic.js`의 인스턴싱 차량·신호등, `world.js`의 셰이더 노면·하늘·건물, `game.js`의 스쿠터·라이더 조립.
- three.js는 저장소의 `vendor/three/`(MIT)를 씁니다. 모듈 import 경로(`./world.js?v=5` 등)는 그대로 두었으니 분리 시 정리가 필요합니다.
